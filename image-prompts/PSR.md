# PSR

## Traits

- 探求型: 教えや体験の意味を深く考え、真理を求める姿勢
- 穏やかな積み重ね型: 日々の恵みや安定した歩みを大切にする感覚
- 受容型: 外に語るよりも、内側で深く受けとめる静かな力

## Description

パウダーブルー背景に、入れ子の円・短い放射線・中心点を配置した抽象アイコンです。静かに探求を重ね、内側で整っていく知恵や落ち着きを表します。

## Prompt

```txt
Create an abstract geometric type icon for a Japanese self-diagnosis app called NBTI.

The icon must be constructed only from the simplest geometric shapes: circles, straight lines, and points. Do not use any complex paths, curves, or decorative elements. The design should be extremely minimal, inorganic, and non-figurative—no suggestion of objects, scenes, or living things.

Style: ultra-minimal thin-line vector icon, geometric glyph, very few elements, large negative space, crisp edges, no fills except for a single small accent, no thick strokes, no heavy shapes, no hand-drawn or painterly effects, no narrative or illustrative elements, square 1:1 icon, full-bleed solid pastel background. The entire canvas must be filled with the specified background color from edge to edge.

Use this unique color palette for PSR: soft powder blue background (#DDE8F4), deep slate blue linework (#334A63), muted periwinkle fills (#7E95C7), cool silver accent (#AEB8C8), and charcoal details (#2F343B). Do not use white, off-white, transparent, or blank backgrounds. Use the specified background color as a full-canvas solid fill. Use flat color with only very subtle gradients if necessary.

The icon should feel like part of a consistent app icon system: thin 1.5px-style linework, balanced spacing, simple geometry, large empty margins, and enough clarity to work at small mobile sizes. Use only outline circles, straight lines, and a single small center point.

Type PSR icon: compose the mark using only concentric circle outlines, a few short straight radial lines, and a single small center dot. Do not use any curves other than perfect circles. No decorative or narrative elements.

Trait translation: inquiry, steady accumulation, inward receptivity. Express these only through the arrangement of circles, lines, and a center point.

Composition: extremely simple, quiet, symmetrical, introspective. Use deep slate blue thin linework, a minimal muted periwinkle accent, and one cool silver center point on the soft powder blue background.

Negative prompt: no thick strokes, no fat lines, no heavy filled shapes, no complex paths, no curves except circles, no decorative elements, no text, no letters, no typography, no people, no faces, no animals, no plants, no leaves, no flower, no mandala, no religious symbol, no cross, no temple, no landscape, no glowing fantasy scene, no mascot, no anime, no illustration scene, no hand-drawn style, no 3D render, no photorealism, no clutter, no messy lines, no busy details, no white background, no off-white background, no transparent background, no blank background.
```
