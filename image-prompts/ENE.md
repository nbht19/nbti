# ENE

## Traits

- 委ねる型: 神様や大きな流れへの信頼、安心して委ねる姿勢
- 逆境からの転換型: 困難や試練を越えて生まれ変わる感覚
- 表出型: 喜びや気づきを外へ分かち合うエネルギー

## Description

柔らかい青背景に、開いた円・上向きの角形・外へ広がる弧を組み合わせた抽象アイコンです。困難を越えて外へ光や力が広がっていく印象を、人物や自然物ではなく無機質な図形で表します。
