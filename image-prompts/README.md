# NBTI Image Prompts

NBTI診断の8タイプ用イメージアイコンを生成するためのプロンプト集です。

## 使い方

各タイプのファイルに、共通プロンプト・タイプ固有プロンプト・ネガティブプロンプトをまとめています。

画像生成AIには、使いたいタイプのファイル内にある `Prompt` セクションをそのまま渡してください。

## タイプ一覧

- `ENE`: 委ねる / 逆境からの転換 / 表出
- `ENR`: 委ねる / 逆境からの転換 / 受容
- `ESE`: 委ねる / 穏やかな積み重ね / 表出
- `ESR`: 委ねる / 穏やかな積み重ね / 受容
- `PNE`: 探求する / 逆境からの転換 / 表出
- `PNR`: 探求する / 逆境からの転換 / 受容
- `PSE`: 探求する / 穏やかな積み重ね / 表出
- `PSR`: 探求する / 穏やかな積み重ね / 受容
