# ESE

## Traits

- 委ねる型: 神様や大きな流れへの信頼、安心して委ねる姿勢
- 穏やかな積み重ね型: 日々の恵みや安定した歩みを大切にする感覚
- 表出型: 喜びや気づきを外へ分かち合うエネルギー

## Description

ミント背景に、なめらかな平行線・丸いノード・外向きの弧を使った抽象アイコンです。安定した流れと、そこから外へ伝わるあたたかさを、幾何学的なパスで表します。
