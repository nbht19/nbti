# ENR

## Traits

- 委ねる型: 神様や大きな流れへの信頼、安心して委ねる姿勢
- 逆境からの転換型: 困難や試練を越えて生まれ変わる感覚
- 受容型: 外に語るよりも、内側で深く受けとめる静かな力

## Description

ラベンダーグレー背景に、中央点・欠けた六角形・内向きの弧を配置した抽象アイコンです。傷や試練を抱えながらも、内側で静かに守り受けとめる感覚を図形で表します。
