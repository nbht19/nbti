# PNE

## Traits

- 探求型: 教えや体験の意味を深く考え、真理を求める姿勢
- 逆境からの転換型: 困難や試練を越えて生まれ変わる感覚
- 表出型: 気づきや確信を外へ言葉にして伝えるエネルギー

## Description

アンバー背景に、中央の菱形・方向を示す角形・外向きの斜線を組み合わせた抽象アイコンです。試練を越えて得た洞察が、外へ向かう確信や指針になる印象を表します。
