# PSE

## Traits

- 探求型: 教えや体験の意味を深く考え、真理を求める姿勢
- 穏やかな積み重ね型: 日々の恵みや安定した歩みを大切にする感覚
- 表出型: 気づきや確信を外へ言葉にして伝えるエネルギー

## Description

ピーチ背景に、螺旋状に並ぶノード・細い接続線・外へ開くガイド弧を使った抽象アイコンです。学びや気づきが積み重なり、外へ共有されていく流れを表します。
