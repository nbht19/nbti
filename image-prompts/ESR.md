# ESR

## Traits

- 委ねる型: 神様や大きな流れへの信頼、安心して委ねる姿勢
- 穏やかな積み重ね型: 日々の恵みや安定した歩みを大切にする感覚
- 受容型: 外に語るよりも、内側で深く受けとめる静かな力

## Description

セージ色の背景に、入れ子の角丸四角形・同心円・中心点を置いた抽象アイコンです。穏やかに積み重なる安定感と、内側に静かに留まる受容性を表します。
